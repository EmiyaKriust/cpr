CPR Virtual Simulator A virtual training software for cardiopulmonary resuscitation (CPR) skills, featuring real-time feedback on compression depth/rate, performance scoring, and instructional demonstration.

Features 3D human model simulating chest compressions and rescue breaths

Real-time display of compression depth, rate, and recoil

Practice mode (free operation) and assessment mode (scoring)

Voice and text prompts to guide proper technique

Running Instructions OS: Windows

Extract and open with Unity

Mouse or touchscreen recommended
